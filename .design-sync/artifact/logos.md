# Logos

`icon.svg` 는 앱 아이콘이다 — 둥근 사각 바탕(`#047857`) 위에 흰(`#FFFFFF`) 마크(오른쪽이 트인 고리와 그 틈의 점).
파비콘·홈 화면 아이콘 자리에만 쓴다.

화면 안의 브랜드 표시는 이 파일이 아니라 `LogoMark` 컴포넌트로 그린다 — `currentColor` 를 받아 `text-emerald-700` 으로
색을 정한다. 잠금(마크 + 제품명 + 설명 한 줄)과 크기 두 가지는 시스템 README 「브랜드 마크 `LogoMark`」에 있다.

아이콘 바탕 `#047857` 은 Tailwind v3 의 emerald-700 값이다. 지금 토큰 `color-emerald-700`(`oklch(50.8% 0.118 165.612)`,
약 `#007a55`)과 조금 다르니 화면 색을 이 파일에서 뽑지 말 것.
